# Using CSS in Express.js

This is a simple Express.js project that shows how to use CSS with Express.js.

## Technologies

* Node.js
* Express.js
* HTML
* CSS

## Project Structure

```text
public/
├── index.html
├── style.css
└── script.js
```

## Express Static Files

```js
app.use(express.static('public'))
```

This allows Express.js to serve the files inside the `public` folder.

## Run

```bash
node public/style.js
